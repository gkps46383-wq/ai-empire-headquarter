# Deployment Guide

## Option A — Open on your device

1. Extract the ZIP.
2. Open `index.html` in Chrome or another modern browser.
3. For best results, keep all project files together in the same folder.

## Option B — Publish using a static hosting service

The project is a static website and does not require a build step.

### General deployment steps

1. Create an account with a static hosting provider such as Vercel, Netlify or GitHub Pages.
2. Create a new site/project.
3. Upload this project folder or connect a Git repository containing it.
4. Set the publish/root directory to the project root (the folder containing `index.html`).
5. No build command is required for this plain HTML/CSS/JavaScript version.
6. Publish and open the generated website URL on your phone and computer.

Provider interfaces and free-tier rules can change. Follow the provider's current setup instructions.

## Before sharing the URL

This starter version has no secure login. Anyone with the URL may be able to use the public prototype, and browser data is local to each visitor. Do not publish confidential company information or use this as a production system until authentication, database permissions and server-side protections are implemented.
